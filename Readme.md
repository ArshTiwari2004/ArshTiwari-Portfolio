## 🚀 Getting Started

Clone and run locally:

```bash
# Clone the repository
git clone https://github.com/ArshTiwari2004/ArshTiwari-Portfolio.git
```

```bash
# Navigate into the project folder
cd portfolio
```

```bash
# Install dependencies
npm install
```

```bash
# Start the development server
npm run dev
```
